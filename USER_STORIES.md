# Пользовательские истории — Трекер расходов

## US-001: Добавление расхода
**Как** пользователь приложения,
**Я хочу** добавить новую запись о расходе (сумма, категория, дата),
**Чтобы** вести учет своих трат.

**Критерии приемки:**
- Есть кнопка "Добавить расход"
- Форма содержит поля: Сумма, Категория, Дата, Комментарий
- После сохранения запись появляется в списке
- Сумма не может быть отрицательной

---

## US-002: Просмотр статистики
**Как** пользователь,
**Я хочу** видеть график расходов по категориям за месяц,
**Чтобы** понимать, на что уходит больше всего денег.

**Критерии приемки:**
- Отображается круговая диаграмма по категориям
- Можно переключать период: неделя / месяц / год

---

## US-003: Установка лимита бюджета
**Как** пользователь,
**Я хочу** установить месячный лимит трат,
**Чтобы** получать уведомление при приближении к пределу.

**Критерии приемки:**
- В настройках есть поле "Лимит на месяц"
- При 80% лимита — желтое предупреждение
- При 100% — красное предупреждение
